This repository contains the monolothic core of [[comp:][The Compiler Company]].

* Source Code
The core is primarily written from scratch in (non-portable) [[https://common-lisp.net][Lisp]] but
also includes dedicated Emacs Lisp and Rust modules.

The Lisp code is divided into separate folders under the top-level
=lisp= folder. There is a standard library named =std=, =ffi= modules
which provide C bindings, =lib= modules for high-level packages, and
=bin= modules containing executable programs. Unit tests can be found
in directories and lisp files starting with =tests= and benchmarks are
contained in the dedicated =bench= directory.

The =emacs= folder contains our core Emacs Lisp code. The contents are
intended to be copied directly into the user's =.emacs.d= and paired
with a user configuration file. The top-level files contain the usual
suspects for a modern Emacs configuration and the =lib= folder
contains various additional packages which enhance our IDE workflow.

Last, we have Rust code which lives under =rust=. There's =lib=,
=bin=, =ffi= modules same as Lisp in addition to =ui=.
