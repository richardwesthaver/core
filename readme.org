This repository contains the monolothic core of [[https://compiler.company][The Compiler Company]].

The core is a [[https://compiler.company/graph/lang/lisp#af0ed8bb-4b45-42f9-b8be-82b8ea7935a3][Common Lisp]] hacking environment bootstrapped from SBCL.
No guarantees are made with respect to compatibility with other
packages or ANSI Lisp implementations.

- install core programs
  #+begin_src shell :eval no
  # sudo pacman -Sy sbcl
  ./bootstrap.lisp #> .stash/core
  sudo .stash/core --script etc/script/install.lisp
  #+end_src

- install emacs site-lisp
  #+begin_src shell :eval no
  # sudo pacman -Sy emacs
  # export EMACSLOADPATH
  skel make install-emacs
  #+end_src
