This repository contains the monolothic core of [[comp:][The Compiler Company]].

The core is a Lisp hacking environment. It is bootstrapped from SBCL
and no guarantees are made with respect to compatibility with other
packages or ANSI Lisp implementations.

#+begin_src shell :eval never
  # cold boot
  sbcl --load bin/script/bootstrap.lisp
  # link to skel
  ln -sf .stash/core .stash/skel
  # warm boot
  .stash/skel make
  # install the core
  .stash/skel install
  # skel homer mpk -> /usr/bin/core
#+end_src
